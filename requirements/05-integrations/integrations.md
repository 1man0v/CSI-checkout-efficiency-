# Интеграции

Источник: Confluence 6318325801, 6323437618.

## Kafka (шина событий телеметрии касс)

- **Назначение:** транспорт событий телеметрии с POS/SCO/Touch/Hybrid в аналитический контур (сегодня используется совместно с Prisma для транспорта событий, согласно описанию текущей реализации).
- **Направление обмена:** касса/кассовое ПО → Kafka → DWH/ClickHouse.
- **Передаваемые данные:** события чеков, состояний кассы, heartbeat (1 раз в минуту) — см. полный список в `requirements/02-system/entities-and-data-dictionary.md`.
- **Формат/способ обмена, аутентификация, обработка ошибок и повторные попытки:** не описаны в исходных документах — см. NEEDS_INPUT ниже.

## POSDWH / DWH

- **Назначение:** хранение сырых событий и расчет агрегатов (почасовых, суточных), расчет медиан и p90/p95.
- **Направление обмена:** Kafka → DWH; DWH → ClickHouse (аналитический слой) и DWH/агрегаты → ЦСЛ.

## ClickHouse

- **Назначение:** аналитическое хранилище, к которому обращаются аналитические модули (в том числе для операционного ИИ-консультанта — см. `requirements/02-system/ai-advisor-concept.md`) и на основе которого строятся отчеты Superset.
- **Направление обмена:** DWH → ClickHouse; ClickHouse → Apache Superset.

## Apache Superset

- **Назначение:** построение аналитических отчетов и дашбордов (Главный дашборд сети, дашборды доступности SCO, производительности POS/SCO, потенциала SCO, таблица аутсайдеров).
- **Направление обмена:** ClickHouse → Superset → Set Centrum (встраивание).

## Set Centrum

- **Назначение:** конечная точка визуализации отчетов для пользователей (ОД/РД/ДМ) — встроенные дашборды Superset отображаются внутри Set Centrum.
- **Направление обмена:** Superset → Set Centrum (embedding).
- **Требование доступности:** должна поддерживать разграничение доступа по ролям пользователей (см. `requirements/04-quality/quality-requirements.md`).

## ЦСЛ (Центральная система логирования/агрегации — по контексту документа)

- **Назначение:** прием агрегированных данных телеметрии из DWH.
- **Направление обмена:** DWH/агрегаты → ЦСЛ (односторонняя отправка).
- **Передаваемые данные:** почасовые и суточные агрегаты (см. `requirements/02-system/entities-and-data-dictionary.md`, раздел «Идентификаторы суточных агрегатов»).
- Отправка агрегированных данных телеметрии через ЦСЛ прямо указана как часть объема MVP1.
