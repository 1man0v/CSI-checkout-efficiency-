## NEEDS_INPUT: Идентификаторы полей в Set

Статус: NEEDS_INPUT

Вопрос: Каковы точные идентификаторы (имена полей/событий) перечисленных выше данных в системе Set — то есть откуда именно (какое событие, какая таблица/топик) берется каждое значение?

Контекст: В исходном документе Confluence для всех перечисленных показателей столбец «Идентификатор в Set» оставлен пустым — то есть маппинг бизнес-показателя на техническое поле не выполнен.

Почему это важно: Без этого маппинга нельзя спроектировать схему данных DWH/ClickHouse и модель событий Kafka (см. `requirements/03-architecture/technical-constraints.md`).
