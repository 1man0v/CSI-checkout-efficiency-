# Офлайн-сборка прототипа (один файл)

Собирает `prototype/` в один самодостаточный HTML-файл — без сервера, без `npm install`, без
интернета. Открывается двойным щелчком в любом браузере, можно отправить коллегам одним файлом
(почта, мессенджер, флешка).

## Сборка

```bash
cd prototype
node backend/seed.js          # чистые демо-данные (пересоздает backend/data/prototype.db)
node offline/export-data.js   # экспортирует все таблицы в offline/data.json
node offline/build-offline.js # собирает offline/set-prototype-offline.html
```

Результат — `prototype/offline/set-prototype-offline.html` (не в git, см. `.gitignore`; пересобирается
локально по мере необходимости).

## Как это устроено

- `export-data.js` — читает уже посеянную SQLite БД и выгружает все таблицы в `data.json`.
- `offline-backend.js` — те же функции, что в `backend/routes/*.js` и `backend/routes/analytics.js`
  (бизнес-логика: агрегаты, доступность, эскалация, распределение по дням/часам), но работают над
  данными в памяти (`window.OFFLINE_DATA`) вместо SQL. Портировано вручную, 1:1 — при изменении
  backend-роутов соответствующую функцию здесь нужно обновить так же.
- `offline-api.js` — заменяет `frontend/api.js`: тот же объект `api` с теми же именами методов, но
  вызывает `offline-backend.js` вместо `fetch()`.
- `build-offline.js` — инлайнит `frontend/styles.css`, `frontend/i18n.js`, `frontend/app.js` (БЕЗ
  ИЗМЕНЕНИЙ — единственная уступка офлайн-режиму — условный блок в `app.js` для пункта
  «Настройки», см. `IS_OFFLINE`), `backend/rules.js` (адаптирован под `window`, сама логика не
  менялась) и встроенные данные в один HTML.

## Известные отличия от серверной версии

- **Настройки (SCR-08)** открываются оверлеем поверх текущего экрана, а не в новой вкладке —
  однофайловая сборка не может открыть второй файл. Функциональность та же (нормативы, согласование
  РД → ОД).
- **Данные не сохраняются** между открытиями файла — изменения (задачи, статусы, настройки) живут
  только в текущей вкладке браузера (сбрасываются при перезагрузке страницы). Об этом сказано в
  баннере внизу страницы.
- Не production-артефакт — как и весь `prototype/`, см. ограничения в
  `ai-artifacts/07-prototype-report.md`.
