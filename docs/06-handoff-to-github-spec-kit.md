# 06. Передача в GitHub Spec Kit

## Работа с NEEDS_INPUT

Перед запуском этапа ИИ рекурсивно проверяет все файлы в `requirements/`. Если незакрытый `NEEDS_INPUT` влияет на результат этапа, ИИ не принимает решение самостоятельно: формирует вопросы в `ai-artifacts/needs-input.md`, задает их Product Manager или клиенту и останавливает этап. После ответа ИИ обновляет исходный файл требований, а Product Manager подтверждает изменение. Только затем этап продолжается.


## Цель этапа

Завершить Product Compiler и подготовить согласованный пакет материалов для инженерной реализации через GitHub Spec Kit и Feature SDD.

Product Compiler не создает production-архитектуру, технические задачи или production-код.

Результат этапа:

```text
NEEDS_INPUT
READY_FOR_GITHUB_SPEC_KIT
```

## Входные данные

```text
Approved Product Model
Approved Screen Model
Approved Visual Prototype
Approved Prototype
Approved Feature Map
```

## Запуск этапа

```text
Прочитай:

ai-artifacts/prompts/06-prepare-github-spec-kit-handoff.md

и выполни инструкции из этого файла.
```

## Что выполняется на этапе

1. Проверить наличие и согласованность всех обязательных артефактов Product Compiler.
2. Сформировать индекс материалов и ссылки на источники.
3. Передать карту функций как точку входа в Feature SDD.
4. Зафиксировать ограничения прототипа и решения, которые должны принять инженеры.
5. Зафиксировать известные риски, зависимости и открытые технические вопросы.
6. Подтвердить отсутствие продуктовых блокеров.

## Создаваемый артефакт

```text
ai-artifacts/09-github-spec-kit-handoff.md
```

Пакет передачи включает ссылки на:

- требования;
- Product Model;
- Screen Model;
- визуальный прототип;
- прототип и отчет по нему;
- Feature Map;
- известные ограничения, риски и инженерные вопросы.

## Следующий процесс

Каждая функция реализуется отдельно через Feature SDD:

```text
Спецификация функции
      ↓
Разъяснение
      ↓
Технический план
      ↓
Задачи
      ↓
Реализация
      ↓
QA
      ↓
Release
```

Не допускается реализация нескольких независимых функций одним большим запросом к ИИ.
